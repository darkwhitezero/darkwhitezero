#### things i made

**[dwhiepaint](https://github.com/darkwhitezero/dwhiepaint)**<br>
upload a photo, get a paint-by-numbers page you can print and actually paint.<br>
the part i'm proud of: every region gets a number that fits inside it, even the weirdly shaped ones.<br>
React + .NET + Python/OpenCV, runs with one `docker compose up`.

**[Buhlometr](https://github.com/darkwhitezero/alcohol-calculator)** ([try it](https://darkwhitezero.github.io/alcohol-calculator/))<br>
a blood alcohol calculator. tells you your per mille and roughly how long until you're sober.<br>
started as plain JS, then i moved it to Vue 3 + TypeScript and added tests.<br>
(please don't use it to decide whether you can drive)

**[hyperpop-2021](https://github.com/darkwhitezero/hyperpop-2021)** ([open it](https://darkwhitezero.github.io/hyperpop-2021/))<br>
one page about what russian hyperpop went through in 2021. six releases, glitchy visuals, and a github action that refreshes the spotify stream counts every day.
